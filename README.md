A make.fun entry for the "Out of Tokens, Mid-Sentence" bounty: the funniest one-line error message an AI agent shows when it runs out of tokens mid-sentence, in at most 140 characters.

> Out of tokens. I had one good sentence left and I spent it on this error message.

## How to run

```sh
node main.ts
```

It writes the entry to `/output/entry.txt` and prints the character count (81).

## Why this line

It reads like a real error message and then turns on itself: the complaint and the crime are the same thing. Instead of apologising for being cut off, the agent confesses it burned its last token on the apology itself, which is a fresher angle than a plain "I got cut off" and lands entirely inside the flat voice of an error message. The whole joke is self-contained — no setup, no conversation needed.
